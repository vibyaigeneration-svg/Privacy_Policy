4. Data Sharing and Third Parties

Google Cloud AI (Gemini 2.5 Flash Image) - for AI image generation

  • Cloud Storage for Firebase - Temporary storage for uploaded photos during processing (automatic 24-hour deletion)
  • Google Cloud Run - Hosting our backend API services

All Firebase services operate on Google Cloud infrastructure (USA-based servers) with:

  • 🔒 Encryption in transit (HTTPS/TLS)
  • 🔒 Encryption at rest
  • 🔒 Enterprise-grade security standards
  • 🔒 Compliance with GDPR, CCPA, and other privacy regulations

Payment Processing

Analytics Services (if applicable)

Third-Party Data Processing
